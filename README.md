# Сервис записи на творческие занятия

Учебный сквозной проект по дисциплине «Технологии разработки приложений на базе фреймворков». ПР1: начальная консольная версия на Python.

## Назначение

Сервис помогает выбрать творческое занятие, проверить условия участия и оформить запись к мастеру.

## Целевая аудитория

Посетители творческих студий, мастера и организаторы занятий по рисованию, керамике и другим видам творчества.

## Предметная область

Мастер проводит занятие в определённую дату. У занятия есть стоимость, количество свободных мест и минимальный возраст. Пользователь записывается на доступное занятие. Запись связывает пользователя с занятием и отражает факт подтверждения участия.

## Основные сущности

- Пользователь: имя и возраст участника.
- Занятие: название, дата, стоимость, свободные места и минимальный возраст.
- Мастер: имя ведущего занятия.
- Запись: связь пользователя с занятием и статус подтверждения.

На ПР1 данные представлены отдельными переменными. Классы и база данных будут добавлены на последующих этапах.

## Основные функции

1. Просмотр информации о занятии: мастер, дата, стоимость, места и возрастное ограничение.
2. Проверка возможности записи: корректность имени и возраста, возрастное ограничение, наличие мест и актуальность даты.
3. Оформление записи после подтверждения: вывод данных записи и уменьшение числа свободных мест на одно. При отказе пользователя или неверном подтверждении запись не создаётся.


## План развития

- ПР2: коллекции занятий и записей, функции, циклы, модули, хранение в файлах и обработка исключений.
- ПР3: классы пользователя, занятия, мастера и записи.
- Следующие работы: Django-приложение, страницы расписания, база данных и связи моделей, формы создания и изменения данных.
- Далее: регистрация и вход, права посетителей и мастеров, отмена записей, REST API, автоматизированные тесты, Docker и CI/CD.
