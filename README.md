# Сервис записи на творческие занятия

Учебный сквозной проект по дисциплине «Технологии разработки приложений на базе фреймворков». ПР2: консольное приложение с меню, коллекциями и сохранением данных в JSON.

## Назначение

Сервис помогает выбрать творческое занятие, проверить условия участия и оформить запись к мастеру.

## Целевая аудитория

Посетители творческих студий, мастера и организаторы занятий по рисованию, керамике и другим видам творчества.

## Предметная область

Мастер проводит занятие в определённую дату. У занятия есть стоимость, вместимость и минимальный возраст. Пользователь записывается на доступное занятие. Запись связывает пользователя с занятием и отражает факт подтверждения участия. Свободные места вычисляются как вместимость минус число активных записей.

## Основные сущности

- Пользователь: имя и возраст участника.
- Занятие: ID, название, дата, стоимость, вместимость и минимальный возраст.
- Мастер: имя ведущего занятия.
- Запись: ID, ID занятия, имя и возраст участника, статус active или cancelled.

На ПР2 занятия и записи представлены списками словарей. Данные мастера находятся в занятии, данные пользователя — в записи. Классы и база данных будут добавлены на последующих этапах.

## Основные функции

1. Просмотр занятий, поиск по части названия без учёта регистра.
2. Фильтрация доступных занятий по возрасту, дате и свободным местам.
3. Сортировка занятий по возрастанию цены или даты.
4. Проверка возможности записи: возраст, дата, места и отсутствие повторной активной записи.
5. Оформление записи после подтверждения и сохранение результата между запусками.
6. Отмена записи по номеру с освобождением места. Отменённая запись остаётся в истории.
7. Просмотр всех записей, добавление занятий и статистика по занятиям, мастерам и статусам записей.

Начальный сценарий ПР1 сохранён в функциях `show_workshop`, `check_booking` и `create_booking`, адаптированных для коллекций. После каждой операции программа возвращается в меню; пункт 0 завершает работу.

## Установка и запуск

Нужен Python 3.10 или новее. Приложение использует стандартную библиотеку. pytest и flake8 нужны только для проверки проекта.

В PowerShell из корня проекта:

```powershell
python -m venv мусор/.venv_pr2
.\мусор\.venv_pr2\Scripts\python.exe -m pip install -r requirements.txt
.\мусор\.venv_pr2\Scripts\python.exe main.py
```

Если окружение уже создано, достаточно последней команды. Вместо `python` при создании окружения можно использовать `py -3` или полный путь к Python. В VS Code выберите интерпретатор `мусор/.venv_pr2/Scripts/python.exe`, откройте `main.py` и запустите отладку текущего файла.

## Хранение данных

`data/state.json` содержит два раздела: `workshops` и `bookings`. Даты хранятся в формате `ГГГГ-ММ-ДД`, а вводятся как `ДД.ММ.ГГГГ`. При запуске данные загружаются, при добавлении занятия, записи или отмене сохраняются. Путь определяется относительно `main.py`, поэтому запуск из другой папки не создаёт отдельный набор данных.

Занятия и записи сохраняются одним файлом: сначала готовится временный JSON, затем он заменяет прежний. При ошибке записи исходный файл и состояние программы остаются прежними. Повреждённый JSON не перезаписывается: программа объясняет проблему и завершает запуск. Если файл отсутствует, открывается пустой каталог, в который можно добавить занятия через пункт 9.

В исходном файле три демонстрационных занятия на 10–12 октября 2026 года. Даты не сдвигаются автоматически. После их наступления можно добавить новое занятие. Данные изменяются при работе приложения, поэтому перед коммитом нужно проверять содержимое `data/state.json`.

## Проверка

```powershell
.\мусор\.venv_pr2\Scripts\python.exe -m pytest
.\мусор\.venv_pr2\Scripts\python.exe -m flake8
```

Для отладки поставьте точку останова на `bookings.append(booking)` в `bookings.py`, запустите `main.py`, выберите пункт 6 и подтвердите запись.

## Ограничения версии

Приложение рассчитано на один запущенный экземпляр и локальные учебные данные. Авторизации и реальной оплаты нет. Участник определяется сочетанием имени без учёта регистра и возраста: полные тёзки одного возраста пока не различаются. Отменить запись может пользователь консоли. Стоимость показывается в рублях; платёжных операций нет.

## Использованные средства Python

Списки и словари хранят данные, множество используется при подсчёте мастеров и проверке ID, цикл `while` повторяет меню. Функция `filter_workshops` использует `yield`, сортировка — `lambda`. Основные функции имеют аннотации типов и docstring. Ошибки обрабатываются через `try/except`, файлы открываются через `with`, временный файл убирается в `finally`.
